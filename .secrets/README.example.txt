투어리스트 비밀키는 Git과 Google Drive 원본 보관소에 넣지 않습니다.

필요한 PC에서만 아래 파일을 직접 만드세요.

  .secrets/youtube_key.txt       YouTube Data API 키 한 줄
  tools/jp/.gemini_key           일본 공식 홀맵 분석용 Gemini API 키 한 줄
  tools/jp/.cse_key              Google Custom Search API key와 cx를 두 줄

실제 값이 든 파일은 모두 .gitignore 대상입니다.
키를 채팅, 문서, 스크린샷, 매니페스트에 복사하지 마세요.
