1. **앱 안의 베타 피드백 버튼** — 유저 의견이 백엔드에 저장되고, 즉시 `brown.rigoon@gmail.com` 으로 메일 알림

## 1. 절대 규칙 (기존 확정 사항 — 위반 금지)

- **위치 좌표(위도·경도)는 어떤 형태로도 수집·전송 금지** (위치기반서비스 신고 의무 — 사장님 확정).
  "어느 위치에서 사용했나"는 **조회한 골프장 소재지의 시/도명**(예: "경기", "제주")으로 대신한다.
  `stats.js` 의 `FORBIDDEN` 정규식과 Code.gs 서버측 차단은 그대로 유지.
- **개인정보 최소화**: 이름·전화·이메일을 유저에게서 받지 않는다. 피드백도 익명(cid만).
  베타 100명은 어차피 아는 사람들이라 회신이 필요하면 배포 채널(카톡 등)로 하면 된다.
- **무료 스택 유지**: Apps Script + 스프레드시트 + MailApp. 서버 비용 0원.
- 신뢰 우선: 통계 숫자도 틀리면 안 보여주느니만 못하다 — admin.html 은 집계 실패 시 "데이터 없음"을 명시.

## 2. ① 베타 피드백 버튼 (프런트)

### 진입점 (2곳, 둘 다 같은 모달)

1. **BETA 배지 탭** — `index.html:135` `<span class="beta-badge">BETA</span>` (버전 표기가 여기 붙는다).
   배지를 탭하면 피드백 모달. 베타 유저에게 "BETA = 의견 받는 중"이라는 자연스러운 신호.
2. **푸터 링크** — 기존 푸터(`💾 기록 지키기 · 이용약관 · …`) 에 `🧪 베타 의견` 추가.

### 모달 구성 (기존 모달 스타일 재사용 — 새 라이브러리 금지)

- 카테고리 칩 4개 (필수): `🐞 오류` `😥 불편` `💡 아이디어` `👍 칭찬`
- 별점 1~5 (선택): "앱, 지금까지 어때요?"
- 내용 텍스트 (필수, 5~500자, `maxlength` + 카운터)
- 자동 첨부 정보를 **모달 안에 투명하게 표시**: "앱 버전 v170 · iOS · 현재 화면: 클럽피팅이 함께 전송됩니다. 이름·연락처는 수집하지 않습니다."
- 안내 문구: "개인정보(이름·전화번호 등)는 적지 말아 주세요."
- 전송 성공 → "고맙습니다! 다음 업데이트에 반영할게요." / 실패 → 큐에 저장 후 "전송 대기 중 — 연결되면 자동 전송"

### 전송 (stats.js 에 추가 — 새 파일 만들지 말 것)

```js
// stats.js 에 FEEDBACK 전송 함수 추가 (statq 큐 패턴 복제, 키는 riweather.fbq)
// POST body: { fn:"feedback", cat, stars, text, screen, cid, ver, dev, t }
// text 는 클라이언트에서도 500자 절단. 성공(r.ok && json.ok) 때만 큐에서 제거.
```

- `screen` = 현재 화면 이름(`showOnly` 가 관리하는 현재 뷰 id). 어느 메뉴에서 불편했는지 파악용.
- 도배 방지는 서버가 담당(아래). 클라이언트는 연속 전송 30초 쿨다운만.

## 3. ② 백엔드 확장 (tools/apps_script/Code.gs)

### 3-1. 피드백 저장 + 메일 푸시

```js
// doPost 에 분기 추가: if (body.fn === "feedback") return fbSave_(body);
// fb 시트: ["시각","cid","분류","별점","내용","화면","버전","기기"]
// 검증: cat 은 4종 화이트리스트, text 5~500자, HTML 태그 제거(<[^>]*> 삭제)
// 도배 방지: CacheService 로 cid 당 하루 5건 제한 ("fbn:"+cid 카운터, 24h)
//            초과 시 { ok:false, err:"limit" } — 앱은 "내일 다시 보내주세요" 안내
// 좌표 차단 정규식은 여기도 동일 적용
```

메일 푸시 (저장 성공 직후):

```js
var ADMIN_MAIL = "brown.rigoon@gmail.com";
MailApp.sendEmail({
  to: ADMIN_MAIL,
  subject: "[골프라이프 베타] " + cat + (stars ? " ★" + stars : "") + " — " + text.slice(0, 30),
  body: 내용 전문 + "\n\n화면: " + screen + " · " + ver + " · " + dev +
        "\n관리자: https://…/admin.html",
});
```

- **한도**: MailApp 은 개인 계정 기준 **하루 100통**. 베타 100명이면 충분하지만,
  안전장치로 메일도 CacheService 일일 카운터("fbmail") **하루 30통** 제한 —
  초과분은 메일 없이 시트 저장만 (피드백 유실은 없다, 알림만 건너뜀).
- 메일 실패해도 저장은 성공 처리 (`try/catch` — 알림은 부가 기능, 데이터가 본체).

### 3-2. 지역(시/도) 수집 — log 시트 9번째 컬럼

- `stats.js` 의 `hit()` 에 선택 인자 `reg` 추가. **course 이벤트에서만** 사용:
  `app.js:820` → `STATS.hit("course", course.name, regionOf(course.addr))`
- `regionOf()`: 주소 첫 토큰에서 시/도 추출 + 정규화("경기도"→"경기", "서울특별시"→"서울" 등 17개 표준).
  주소가 없으면 빈 문자열. **좌표는 건드리지도 않는다.**
- Code.gs: `sheet_()` 헤더에 "지역" 추가, doPost 9번째 컬럼 기록, `FORBIDDEN` 검사 유지.
  기존 행은 8컬럼이어도 무방(빈칸 처리).

### 3-3. 관리자 조회 API 확장 (doGet, 모두 `pw` 필수)

| 엔드포인트 | 반환 |
|---|---|
| `fn=summary` (확장) | 기존 + `regions`(지역 top), `uniqTotal`(순방문자 총계), `retention`(7일 내 재방문 cid 비율), `perDay` 에 피드백 건수 |
| `fn=fblist` (신규) | fb 시트 최근 200건, 최신순. `{ rows:[{t,cat,stars,text,screen,ver,dev,cid}] }` |

### 3-4. 보안 소정리 (이번 기회에)

- `ADMIN_PW` 를 코드 하드코딩 → **스크립트 속성 `ADMIN_PW`** 로 이전
  (`PropertiesService.getScriptProperties().getProperty("ADMIN_PW") || "golf2026!"` — 속성 없으면 기존값 폴백이라 무중단).
  깃허브가 공개 저장소가 될 가능성에 대비해 실제 비밀번호가 코드에 남지 않게 한다.
- `BACKEND_VER = "2026-07-31a"` 로 올릴 것 (verify_deploy 가 서버와 대조하므로 **재배포 전에는 verify 가 실패하는 게 정상**).

## 4. ③ 관리자 프로그램 (admin.html — 저장소 루트, 신규)

**형태**: 파일 하나짜리 자급자족 페이지(외부 라이브러리·CDN 금지, 인라인 CSS/JS).
GitHub Pages 로 앱과 함께 배포되는 "숨은 주소" — robots.txt 가 이미 전체 차단이라 검색 노출 없음.
페이지 소스에는 비밀 데이터가 전혀 없고, **모든 데이터는 비밀번호를 넣어야 백엔드에서 온다**.

### 화면 구성 (위→아래)

1. **비밀번호 입력** — sessionStorage 에만 유지(탭 닫으면 소멸). 틀리면 백엔드가 err 반환.
2. **핵심 숫자 카드 4개**: 오늘 방문(명/회) · 누적 순방문자 · 7일 재방문율 · 새 피드백 수
3. **일별 방문 추이** (최근 30일, 순방문자/총방문 — CSS 막대 그래프면 충분, canvas 불필요)
4. **메뉴별 사용** (weather/course/food/score/stay/booking/clubfit + ai·booking_out 등 — 한글 라벨 매핑 필수: "clubfit"→"클럽 피팅")
5. **지역별 사용** (시/도 top 10)
6. **인기 골프장 top 20**
7. **기기 / 연령대 / 성별** (연령·성별엔 "동의자만 집계" 주석 표시)
8. **피드백 목록** — 분류 칩 필터, 최신순, 별점·화면·버전 표시. 새로고침 버튼.

### 만들 때 주의

- 모바일에서 사장님이 볼 것 — 세로 1열 카드 레이아웃, 폰트 크게.
- 집계가 비어 있으면 "아직 데이터가 없습니다" 를 명시(0 과 무데이터를 구분).
- pw 는 GET 파라미터로 전달(기존 summary 패턴 유지, HTTPS 라 노출 위험 낮음). URL 에 pw 를 북마크하지 말라는 안내 한 줄.
