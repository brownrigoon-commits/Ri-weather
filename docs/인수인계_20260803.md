## 새로 생긴 관문 (배포 전 반드시 통과)

```bash
python tools/check_i18n.py          # 문구 사전 — 키·값·번역기 표식·option value
python tools/check_ko_literal.py    # 화면 그리는 코드에 박힌 한국어
node tools/jp/check_applink_jp.js   # 일본 자료가 앱 코드로 실제 닿는지
```

세 개 다 **일부러 고장 내어** 잡는 것을 확인해 두었다.

### `check_ko_literal.py` 가 **못 잡는 것** — 알고 쓸 것

한 줄에 화면을 만드는 신호(innerHTML·태그)가 같이 있어야 잡는다.
**표(배열)로만 적힌 한국어는 지나친다.** 실제로 놓쳤다:

```js
const CITY_LABELS = [ ["서울", 37.566, 126.978], ["도쿄", 35.690, 139.692], … ]
```

표를 조건 없이 잡으면 프로토콜 값 표까지 걸려 검사가 쓸모없어진다.
→ **표에 한국어를 담을 때는 사람이 스스로 물어야 한다: 이 글자가 화면에 나가는가.**

## 반드시 지킬 원칙 (오늘 값비싸게 배운 것)

### 1. 값과 글자를 가른다

번역하면 **조용히** 깨지는 것들이 있다. 값은 한국어로 두고 글자만 사전을 거친다.

| 자리 | 왜 |
|---|---|
| `<option>` | value 가 없으면 **글자가 곧 값**이다. 옮기면 저장된 "화이트" 와 어긋난다 |
| 프로필 칩 | localStorage 에 저장되고 문자열 동치로 분기한다 |
| 홀 공략 좌/우/벙커 | 방향 판정에 쓴다 |
| 주소 종류 | `centerNote` 가 정규식으로 본다 |
| **클럽 DB** | `=== "낮음"` · `=== "스틸"` 같은 판정이 40군데 넘는다 |

확인해 둔 것: "드로우" 로 저장한 프로필이 일본어 화면에서 「ドロー」로 보이고 저장값은 그대로.

### 2. 화면을 훑는 것만으로는 부족하다

브라우저 스캔은 **그때 떠 있는 것만** 본다.
권유 카드는 '아직 대답 안 한 사람' 에게만 떠서 못 봤고 그대로 배포됐다.
→ 소스를 뒤지는 관문이 필요하다(그래서 `check_ko_literal.py` 를 만들었다).

### 3. 모르면 지어내지 않는다

* 나고야GC 홀 번호 — OSM way 순서는 라운드 순서가 아니다. 1·2·3 을 매기지 않고 위성 전경만.
* 예약처 없는 구장 — "예약이 안 됩니다" 가 아니라 "우리에게 자료가 없다" 라고 쓴다.
* 숙박 사진 — 좌표로만 짝지으면 10곳 중 7곳이 엉뚱한 호텔이다(실측). 이름까지 맞을 때만 붙인다.

### 4. 주석 안에 별표+슬래시를 쓰지 말 것

`'/gc*/'` 를 그대로 적었다가 블록 주석이 거기서 닫혀 문법 오류가 났다. **두 번째다.**
