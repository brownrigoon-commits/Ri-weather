>
> 실측(2026-08-01, 전부 원문 확인):
> - **사이트맵에 구장 페이지 2,433개** 등재 (`golf-jalan.net/sitemap.xml`) — 전 구장 열거 문제가 없다
> - robots.txt **`Allow: /`** (회원·예약 경로만 차단) — 상세 페이지·이미지 수집 허용
> - `/gc{5자리}/detail/` 에 홀맵 그림 + 홀별 파·티별 야드 + **홀별 한 줄 코멘트**(figcaption)까지
> - 표본 3곳 전부 그림 보유: PGM 구장(자체 사이트엔 그림 없음!)·아코디아 구장·**독립 구장**(大宮国際)
> - 이미지: `img.golf-jalan.net/image/course/G{내부id}/{코스id}_{홀}.jpg` — **235×255 한 판뿐**
>   (큰 판 변형 6종 시도 전부 404 실측)

**화질 사다리 — 같은 구장에 두 출처가 있으면 좋은 그림이 이긴다:**

| 순위 | 출처 | 곳수 | 화질 | source 표기* |
|---|---|---|---|---|
| 1 | 아코디아 | 169 (golfdb 매칭 104) | **540×900 고화질** | `アコーディア` |
| 1 | 東急 12 · 東京建物 9 · 多摩興産 3 | 24 | 착수 시 실측 | `東急`/`東京建物`/`多摩興産` |
| **2 (등뼈)** | **じゃらんゴルフ** | **~2,433 페이지 (그림 보유율은 1일차 전수 실측)** | 235×255 저화질 | `じゃらん` |
| 부킹 전용 | GORA | 가이드 페이지에 **홀맵 없음** (c_id 165·1067 실측 — layout_thumbnail 은 UI 아이콘) | — | — |

\* source 표기는 **`tools/jp_takedown.py` 의 SOURCES 표와 글자까지 일치**해야 내리기 스위치가 잡는다.
   じゃらん 항목(`jalan` / mark `じゃらん` / site `golf-jalan.net`)을 SOURCES 에 추가할 것.

**じゃらん 수집 규격 (오퍼스 구현용):**
- 인덱스: `sitemap.xml` 의 gc 페이지 2,433개 (현별 목록 페이지는 404 — 사이트맵이 유일한 열거 수단)
- 파싱: `【HOLE N】PAR:4` + `510/486/432 yd`(티 수 구장마다 3~4) + `<figure><img …><figcaption>코멘트`
- 구장명: `<title>` 에서 `【ＰＧＭ】【アコーディア】` 같은 체인 꼬리를 떼고 NameResolver 로 golfdb 대조
- 이미지 검증: 매직넘버 + **최소 2KB** (독립 구장 표본이 4KB — 아코디아 기준 10KB 를 그대로 쓰면 오탐)
- ⚠️ **홀별 코멘트는 복제 금지.** "S字の長いミドルホール" 같은 문구는 じゃらん/구장 저작물이다.
  도그레그 방향·해저드 같은 **사실만 추출**해 AI 캐디의 입력 재료로 쓰고, 문장은 우리가 만든다
  (東京建物 공략문과 같은 취급 — L3 원칙 그대로).
- 저작권 취급은 한국 골프존과 동일: source 표기 + 내리기 스위치 + 일본 논의 협상 카드.
  robots 허용·사이트맵 등재가 신사협정상 청신호라는 것도 골프존 때와 같다.

**기대 커버리지: 104곳 → 최대 ~1,900곳** (golfdb 2,014곳 대비 90%+.
정확한 수는 1일차에 사이트맵 전수를 돌려 "그림 있는 구장 수 × golfdb 매칭"으로 실측한다.)

- 🔴 아코디아 함정(실측): 호스트가 `www` 면 **HTTP 200 인데 내용은 1,465B HTML 오류 페이지**다.
  반드시 `reserve` 호스트 + **Content-Type 이 image/* 인지 검증** + 크기 하한(>10KB) 검사.
- A/B 그린 2세트 구장(소부 실측): A그린만 등록, parsed.json 에 `green:"A"` 명기.

### 2-4-1. 🔴 실제로 수집해 보고 알게 된 것 (2026-08-01, 샘플 3구장)

설계 단계에서 몰랐던 것들이다. **다음 출처(東急·東京建物·多摩興産)를 붙일 때도 같은 함정이 있다.**

| 알게 된 것 | 왜 위험한가 | 대응(구현됨) |
|---|---|---|
| **27홀 구장은 세 코스가 모두 1~9번홀** | 홀 번호로 코스 이름을 정하면 전부 'OUT' 이 되어 **그림 파일이 서로를 덮어쓴다.** 27홀로 멀쩡해 보이는데 실제 그림은 9장뿐 | 코스 이름을 페이지의 **문서 위치**로 짝지음(`NAME → 표 → 그림 N_1` 순서). 이름 없거나 겹치면 등록 거부 |

## 4. 숙박 — 라쿠텐 트래블 API

- **키**: 라쿠텐 applicationId(GORA 와 공용)+affiliateId — **사장님(Phase 0)**.
- **호출**:
  ```

    ?applicationId={ID}&affiliateId={AFF}&latitude={lat}&longitude={lon}
    &searchRadius=3&datumType=1&format=json
  ```
- 🔴 **측지계 함정(GORA 좌표와 같은 계열)**: `datumType=1`(세계측지계) 명시 필수 —
  기본값이 일본측지계인 판이 있어, 빼면 수백 m 어긋난다. **착수 시 1회 실측**으로 확정.
- ⚠️ **레거시 API 예제 금지** — 2026-02-09 폐지됨(조사 §2). 현행 20170426 판만.
- JSONP: GORA 에서 callback 지원 실측됨 — 같은 플랫폼이라 트래블도 가능 추정, **착수 시 1회 확인**.
- **매핑** (stay.js 정규형 `{id,name,cat,kind,...}`): 이름=`hotelName`, 가격=`hotelMinCharge`
  (**¥ — stay.js:151 won() 을 fmtPrice(n,cur) 로**, D8), 사진=`hotelImageUrl`,
  평점=`reviewAverage`/`reviewCount`, 링크=`hotelInformationUrl`(affiliateId 넣으면 제휴 URL 반환).
- 링크 카드: 야놀자·여기어때 자리 → 라쿠텐트래블·자란(리크루트) 링크로 교체(JP 프로필에서만).
