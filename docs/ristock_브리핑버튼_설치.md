# 📈 Ri_Stock '브리핑 다시 받기' 켜기 (사장님이 5분, 한 번만)

앱 브리핑 맨 위의 **[브리핑 다시 받기]** 버튼을 진짜로 동작하게 하는 설정입니다.

## 지금은 어떻게 동작하나

| 이 설정 전 | 이 설정 후 |
|---|---|
| 버튼을 누르면 **최신 데이터만 다시 불러옵니다** (몇 초) | 버튼을 누르면 **그 자리에서 다시 수집합니다** (1~3분) |
| 새 회차가 없으면 화면이 그대로입니다 | 지수·뉴스를 지금 시각으로 새로 받아 화면이 바뀝니다 |

버튼은 지금도 눌러도 안전합니다. 설정이 없으면 "서버 재수집이 아직 연결되지 않아
최신 데이터만 다시 불러왔습니다" 라고 솔직히 알려 줍니다.

## 왜 이런 설정이 필요한가

앱은 깃허브에 올라간 **정적 화면**이라 폰에서 수집을 직접 돌릴 수 없습니다.
(브라우저에서 야후·네이버를 부르는 것조차 막혀 있습니다 — 2026-07-28 확인)
그래서 골프앱이 쓰는 **백엔드(Apps Script)** 가 대신 깃허브 수집을 눌러 주는데,
깃허브가 "누가 눌렀는지" 확인할 열쇠(토큰)가 필요합니다.

**받는 것은 지수 시황 + 10개국 뉴스뿐입니다** (18초~3분).
종목 600개는 다시 받지 않으므로 전략·종목 화면은 그대로 유지됩니다.

---

## 1단계 — 깃허브 토큰 만들기 (2분)

1. <https://github.com/settings/personal-access-tokens/new> 접속 (로그인 필요)
2. 아래처럼 채웁니다.

   | 칸 | 넣을 값 |
   |---|---|
   | Token name | `ristock-브리핑버튼` |
   | Expiration | 원하는 기간 (1년 권장 — 만료되면 버튼만 멈춥니다) |
   | Resource owner | 본인 계정 (brownrigoon-commits) |
   | Repository access | **Only select repositories** → `Ri-weather` 선택 |

3. **Permissions → Repository permissions** 에서 딱 하나만 켭니다.
   - **Actions: Read and write**
   - 나머지는 전부 `No access` 그대로 둡니다. (이 토큰으로는 코드를 못 고칩니다)

4. 맨 아래 **Generate token** → 나오는 `github_pat_…` 문자열을 복사합니다.
   ⚠ 이 화면을 벗어나면 다시 볼 수 없습니다. 복사해 두세요.

## 2단계 — 백엔드에 토큰 넣기 (2분)

1. 골프라이프 통계 스프레드시트 → **확장 프로그램 → Apps Script**
2. 왼쪽 **⚙️ 프로젝트 설정** 클릭
3. 아래 **스크립트 속성** → **속성 추가**

   | 속성 | 값 |
   |---|---|
   | `GITHUB_TOKEN` | 1단계에서 복사한 `github_pat_…` |

4. **스크립트 속성 저장**

> 토큰은 코드가 아니라 이 속성 칸에 들어갑니다.
> 저장소에는 올라가지 않으므로 깃허브에서 볼 수 없습니다.

## 3단계 — 백엔드 코드 새로 올리고 재배포 (1분)

1. Apps Script 편집기에서 기존 코드를 모두 지우고,
   `tools/apps_script/Code.gs` 내용을 **전체 복사해 붙여넣기** → 저장(💾)
2. 오른쪽 위 **배포 → 배포 관리** → 연필(✏️) → 버전 **새 버전** → **배포**
   - 주소(URL)는 그대로 유지됩니다. 앱을 고칠 필요가 없습니다.

⚠ **저장만 하면 서버에 반영되지 않습니다.** 반드시 '새 버전'으로 재배포하세요.
(이 저장소에서 두 번이나 "코드는 고쳤는데 배포를 안 해서" 기능이 죽어 있었습니다)

---

## 잘 됐는지 확인

폰에서 앱을 열고 **[브리핑 다시 받기]** 를 누릅니다.

| 화면에 뜨는 말 | 뜻 |
|---|---|
| "브리핑을 다시 만들고 있습니다" → 1~3분 뒤 "새 브리핑이 도착했습니다" | ✅ 정상 |
| "방금 한 번 돌렸습니다. 3분 뒤에 다시 눌러 주세요" | ✅ 정상 (겹쳐 도는 것을 막는 장치) |
| "서버 재수집이 아직 연결되지 않아…" | 토큰이 없거나 재배포를 안 한 상태 → 2·3단계 다시 |
| "재수집 요청이 닿지 않아(깃허브거부)…" | 토큰 권한이 모자람 → 1단계에서 **Actions: Read and write** 확인 |

깃허브 쪽 기록은 저장소 **Actions 탭 → Ri_Stock 일일 자동 갱신** 에서 볼 수 있습니다
(브리핑만 갱신한 회차는 '브리핑만 갱신' 스텝만 초록으로 켜집니다).

## 나중에 끄고 싶으면

Apps Script 프로젝트 설정에서 `GITHUB_TOKEN` 속성을 지우면 됩니다.
버튼은 다시 '최신 데이터 다시 불러오기' 로 조용히 물러납니다 — 앱은 그대로 동작합니다.
