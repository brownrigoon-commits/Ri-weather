# 일본 숙박 커버리지 실측 (2026-08-02)

> 라쿠텐 트래블 施設検索API `SimpleHotelSearch/20260731` · 반경 3km · datumType=1(세계측지계)
> 대상: 홀맵이 있어 코스공략이 뜨는 **645구장** · 배포 도메인에서 실행 · 오류 0건

## 왜 쟀나

"주변 숙박" 을 만들기 전에 **자료가 실제로 있는지** 먼저 확인했다.
설계에 적힌 3km 반경이 일본 골프장에 맞는지 추측하지 않고 전수로 셌다.

## 결과

| 3km 안 숙소 | 구장 수 | 비율 |
|---|---:|---:|
| **0곳** | **174** | **27%** |
| 1곳 | 159 | 25% |
| 2~4곳 | 173 | 27% |
| 5~9곳 | 72 | 11% |
| 10~19곳 | 28 | 4% |
| 20곳+ | 39 | 6% |

**0곳 또는 1곳뿐인 구장이 333곳(52%)** — 절반이 숙박 메뉴로서 성립하지 않는다.

많은 곳은 관광지형이다(大箱根CC 98 · ゴールド川奈 289 · 西熱海 154 · ベルビーチ 117).
없는 곳은 산속 구장이다(キャッスルヒル · 千葉桜の里 · 東条GC …).

## 확인된 API 제약 (설계와 달랐던 것)

1. **엔드포인트가 바뀌었다.** 설계의 `app.rakuten.co.jp/services/api/.../20170426` 은 폐기.
   현행 `https://openapi.rakuten.co.jp/engine/api/Travel/SimpleHotelSearch/20260731`
2. **인증이 두 값이다.** `applicationId`(UUID) + `accessKey`(pk_…) 를 **둘 다** 보내야 한다.
   예전처럼 applicationId 하나만 보내면 `wrong_parameter`.
3. **`searchRadius` 상한은 3km 하드 리밋** — `searchRadius must be under 3.0`.
   5·10·15·20km 는 전부 400 으로 거부된다. **반경 파라미터로는 넓힐 수 없다.**
4. **헤더 인증은 브라우저에서 못 쓴다.** `Authorization`·`x-api-key` 를 붙이면
   CORS 프리플라이트에 걸려 요청 자체가 실패한다. **쿼리 파라미터로만** 보낼 것.
5. **CORS 는 열려 있다** — 프록시 없이 브라우저에서 직접 호출된다(설계의 확인 항목 해소).
6. **서버(Referer 없음)에서는 403** — 앱을 http_referrer 형으로 등록했기 때문.
   도구도 배포 도메인에서 돌려야 한다. Referer 위조는 하지 않는다.

## 거리별 채움률 — 3km 0건 구장 표본 30곳 (2026-08-02 실측)

3km 반경 밖으로 3km 원을 **링** 으로 깔아(6km 링 → 9km → 12km) 처음 숙소가 잡히는 거리를 쟀다.

| 채워진 거리 | 구장 수 | 누적 |
|---|---:|---:|
| **6km 안** | **27** | 90% |
| 9km 안 | 3 | **100%** |
| 12km 밖 | **0** | — |

**30곳 전부 9km 안에서 채워졌다.** 12km·15km 까지 갈 필요가 없다.

**호출 비용: 구장당 평균 2.6회** (30곳 78회). 링의 첫 점에서 바로 잡히는 경우가 많아
최악(6점×3링=18회)에 한참 못 미친다.

## 결론 — 이렇게 간다

**① 링 방식으로 간다.** ②(지역 코드)는 "주변" 이 아니게 되므로 쓰지 않는다.

```
1단계  구장 좌표 3km            → 있으면 끝  (645곳 중 471곳, 73%)
2단계  6km 링 (3km 원 6~8개)    → 여기서 90% 해결
3단계  9km 링                   → 나머지 10%
그래도 없으면 "주변 숙소를 찾지 못했습니다" 라고 정직하게 적는다 (지금 표본에는 없었다)
```

- 화면에는 **구장에서 실제 거리(km)를 함께** 적는다 — "8.2km" 를 숨기고 '주변' 이라 하지 않는다.
- 예상 총 호출: 645곳 × 평균 1.4회 ≒ **900회** (0건 구장 174곳만 2단계 이후로 간다).
- 라쿠텐에 신고한 2 QPS 안에서 1.3초 간격이면 약 20분.

⚠️ 배치로 미리 받아 두는 것은 **숙소 번호(hotelNo)와 거리까지만** 이다.
   가격·평점·빈방은 **그때그때 받아야 한다** — 값이 변하는 것을 굳혀 두면 틀린 정보가 된다
   (신뢰 우선 원칙). 앱은 저장된 hotelNo 로 1회 호출해 현재 값을 받는다.
