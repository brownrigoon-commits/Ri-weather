**가장 큰 두 가지**

* **파 4 지어내기** — 조립기가 `h.get("par") or 4` 였다. 화면뿐 아니라 **AI 캐디에게 "파4"라고 사실처럼**
  전달됐다. 이제 모르면 비운다(앱은 홀 번호만 보여준다).
* **코스명 지어내기** — `golfzon_build.py` 가 구장명에 ' - ' 가 없으면 무조건 OUT/IN 을 붙였는데,
  같은 원본 JSON 의 `holeInfo.courseTypes` 에 진짜 이름이 있었다. 태인CC=LAKE·MOUNTAIN,
  포천힐스=CASTLE·PALACE·GARDEN. **예약한 코스를 앱에서 못 찾던 문제**다.

## 알아 두면 헤매지 않는 것

* **`official_scan.js` 는 `--new` 없이 돌리면 이미 훑은 곳을 다시 두드린다.** 결과 파일을 덮어쓰는
  구조였다 — 오늘 이어붙이기 모드를 넣었다.
* **`official_collect.py --collect` 는 정적 HTML 만 읽어 자바스크립트 홀맵을 못 본다.** 실측에서
  브라우저로는 18홀이 잡힌 구장이 정적으로는 "못 찾음"이었다. 그래서 `official_collect_from_dom.py`
  (이미 찾아 둔 주소만 내려받기)를 만들었다. 대상을 좁히는 `--only-list` 도 넣었다.
* `.bak` 과 `tools/__pycache__` 는 이제 무시된다(`reparse_holes.py` 가 86개를 만들어 `sync.py` 에
  딸려 갈 뻔했다).
* `tools/jp/safe_commit.py` 의 집 PC 하드코딩 경로를 스크립트 기준으로 고쳤다 — 양쪽에서 다 된다.
* 브라우저 창이 화면에 안 떠 있으면 스크린샷은 실패하지만 `javascript_tool`·`read_page` 로 화면을
  다 확인할 수 있다. 구글 콘솔의 드롭다운은 pointerdown/mouseup 을 직접 쏘면 열린다.
* **reCAPTCHA 는 2분이면 만료된다.** 폼을 다 채워 두고 마지막에 체크해야 버튼이 켜진다.
