# 클럽 피팅 재설계 — 질문 설계안 (검토용)

작성 2026-07-27 · **구현 전 검토 단계**. 사장님 확인 후 코드에 반영합니다.
현재 구현: `js/clubfit.js` (드라이버 8+5문항 → 내 백 허브 → 아이언/웨지/퍼터 각 4문항)

## 0. 무엇을 바꾸나

| | 지금 | 바꿀 것 |
|---|---|---|
| 진입 | 드라이버 피팅이 강제 시작 → 끝나야 나머지 | **첫 화면에서 4개 중 선택** |
| 신체·실력 | 드라이버 문항에 섞여 있음 | **공통 블록으로 분리, 최초 1회만** |
| 브랜드 | 드라이버는 앞, 나머지는 뒤 | **클럽 선택 직후 헤드·샤프트 브랜드 먼저** |
| 문항 수 | 아이언 4 / 웨지 4 / 퍼터 4 | **아이언 14 · 웨지 7 · 퍼터 11** (1차 / 정밀 2단계) |
| 그립 | 드라이버 결과에만 한 줄 | **독립 문항 3개 + 모든 클럽 결과에 포함** |

### 새 흐름

```
[1] 클럽 선택          드라이버 · 아이언 · 웨지 · 퍼터   (실루엣 아이콘 4개)
      ↓
[2] 나에 대해 (공통)    성별·나이·구력·평균타수·키·체력·장갑호수
                       ※ 최초 1회만. 두 번째 클럽부터는 "이대로 진행" 확인만
      ↓
[3] 선호 브랜드         헤드 브랜드 / 샤프트 브랜드  (선택한 클럽에 맞는 목록)
      ↓
[4] 클럽별 전문 문항     1차 → (결과 바로 보기 가능) → 정밀
      ↓
[5] 결과 + 그립 추천
```

`[2]`는 `localStorage riweather.fitprofile` 에 저장. 드라이버 하고 아이언 하러 오면 다시 안 묻습니다.

## 1. 공통 블록 — "나에 대해" (최초 1회, 6문항)

이미 아는 것은 **묻지 않고 카드로 보여주고 확인만** 받습니다 (기존 원칙 유지).

| 항목 | 출처 | 질문 여부 |
|---|---|---|
| 연령대 · 성별 | 동의 화면 | 확인만 |
| 평균 타수 | 스코어 기록 | 확인만 (기록 없으면 질문) |
| 후반 패턴(체력 신호) | 스코어 13~18홀 분석 | 자동 |

**새로 묻는 것**

- **C1. 구력** — 3년 미만 / 3~10년 / 10년 이상  *(기존 유지)*
- **C2. 키** — 슬라이더 150~195cm  *(기존 유지)*
- **C3. 손목–바닥 거리** — 슬라이더 + "모름" `선택`
  > 서서 팔을 늘어뜨렸을 때 **손목 주름에서 바닥까지**. 길이·라이각의 진짜 기준은 키가 아니라 이 값입니다.
  > 키만으로 라이각을 정하면 팔 긴 사람·짧은 사람이 반대로 나옵니다.
- **C4. 장갑 호수** — 남 21~26호 / 여 18~21호 / 모름 → **그립 사이즈용**
- **C5. 18홀 체력** — 거뜬 / 후반에 무너짐 / 18홀도 벅참  *(기존 유지)*
- **C6. 몸 상태** `선택` 복수 — 손목·팔꿈치 아픔 / 허리 아픔 / 손가락 관절 / 해당 없음
  > 통증이 있으면 무게·소재 추천이 완전히 달라집니다(그라파이트·경량 강제).

> ### ❓ 검토 필요 — 넣을지 말지
> **주 플레이 환경** — 필드 위주 / 스크린 위주 / 반반
> 스크린 위주면 관용성보다 타감·일관성 가중치가 커집니다. 한국 시장에선 유의미한데, 문항이 하나 늘어납니다.

## 2. 아이언 — 질문 설계 (사장님 요청 핵심)

### 왜 이 질문들인가

실제 아이언 피팅이 결정하는 것은 **7가지**입니다. 각 질문은 이 중 무엇을 정하는지가 분명해야 합니다.

| 결정 항목 | 무엇으로 정하나 | 해당 질문 |
|---|---|---|
| ① 헤드 타입 (머슬/캐비티/중공/맥스) | 실력 + 어드레스 취향 + 관용성 요구 | I6, I7 |
| ② 샤프트 소재 (스틸/그라파이트) | 스피드 + 체력 + 통증 | I5, C5, C6 |
| ③ 샤프트 무게 | 7번 캐리 + 체력 + 템포 | I1, C5, I12 |
| ④ 샤프트 강도(플렉스) | 7번 캐리 + 전환 급함 | I1, I12 |
| ⑤ 킥포인트(탄도 성향) | 현재 탄도 + 미스 경향 | I3, I2 |
| ⑥ 라이각 · 길이 | 손목–바닥 + **볼자국 위치** + **디봇 방향** | C3, I9, I10 |
| ⑦ 세트 구성 (몇 번부터) | 긴 아이언 실사용 여부 | I8 |

### 아이언 1차 — 8문항 (이것만으로도 추천 가능)

**I1. 7번 아이언 캐리는?**
슬라이더 110~185m + **「모르겠어요」 추가**
> 런 빼고 떨어지는 지점까지. 헤드스피드를 가장 정확히 알려주는 숫자입니다.
> `모르겠어요` → 평균타수·성별·연령으로 **추정**하고, 결과에 "추정값 기준"이라고 밝힙니다.

**I2. 아이언이 빗맞을 때 주로 어떻게 되나요?** *(기존 유지)*
얇게 맞아요 / 뒤땅을 쳐요 / 방향이 흔들려요 / 특별한 경향 없음

**I3. 아이언 탄도는 어떤가요?** 🆕
낮아요(그린에 안 서요) / 적당해요 / 너무 떠요(거리 손해)
> 지금은 **드라이버 탄도만** 묻고 아이언 킥포인트를 거기서 유추하고 있습니다. 둘은 다릅니다.

**I4. 아이언 구질은?** *(기존 유지)*
슬라이스 / 스트레이트 / 훅

**I5. 샤프트 소재, 정해두신 게 있나요?** *(기존 유지)*
골라주세요 / 스틸 / 그라파이트

**I6. 어드레스에서 어떤 모양이 편하세요?** 🆕 — 헤드 타입의 진짜 기준
- 얇고 깔끔한 것 — 톱라인 얇고 오프셋 적음
- 보통
- 두툼하고 든든한 것 — 빗맞아도 손해 적음
- 잘 모르겠어요 — 실력에 맞게 골라주세요
> 지금은 평균타수만으로 헤드를 정합니다. 80대인데 맥스 캐비티를 좋아하는 분, 100타인데 얇은 걸 원하는 분이 실제로 많습니다.

**I7. 지금 아이언에서 제일 아쉬운 건?** 🆕
거리 / 방향 / 탄도 / 타감 / 빗맞을 때 손해 / 딱히 없음
> **"그대로 쓰세요(KEEP)" 판정의 근거**입니다. 드라이버엔 있는데 아이언엔 없어서, 지금은 아이언에서 KEEP 판정이 아예 안 나옵니다.

**I8. 세트에서 가장 긴 아이언은 몇 번이고, 잘 맞으세요?** 🆕
4번부터 / 5번부터 / 6번부터 / 모름  ＋ 그 클럽 — 잘 맞아요 / 자신 없어요
> 아마추어에게 **가장 값어치 있는 조언**이 여기서 나옵니다: "4·5번은 빼고 유틸리티로 바꾸세요."
> 클럽을 파는 조언이 아니라 **줄이라는 조언**이라 신뢰로 이어집니다.

### 아이언 정밀 — 6문항 (라이각·길이·세트까지)

**I9. 페이스에 볼자국이 어디에 남나요?** 🆕 — 라이각 핵심 근거
토우(끝) 쪽 / 가운데 / 힐(안쪽) 쪽 / 확인해본 적 없어요
> 확인 방법을 그림으로 안내 (페이스에 파운데이션·마커 바르고 한 번 치기)

**I10. 디봇이 어느 쪽을 향하나요?** 🆕 — 라이각 보조 근거
타깃보다 왼쪽 / 곧게 / 타깃보다 오른쪽 / 디봇이 잘 안 생겨요

> ⚠️ **I9·I10으로 라이각을 "확정"하면 안 됩니다.**
> 정적 측정 + 임팩트 테이프가 있어야 확정입니다. 앱은 **"업라이트 쪽으로 1~2° 볼 것"** 처럼
> 방향과 범위만 제시하고 **"샵에서 라이각 확인 필요"** 를 함께 띄웁니다.
> — 절대 원칙 2 (틀릴 수 있으면 표시하지 않음)

**I11. 어떤 타감을 좋아하세요?** *(기존 유지)*
부드러운 / 단단한 / 가벼운 / 상관없음

**I12. 스윙 템포는?** — 드라이버에서 공통으로 이동
부드러움 / 보통 / 빠름(전환이 급함)

**I13. 피칭웨지 로프트가 몇 도인가요?** — 웨지에서 공통으로 이동
슬라이더 41~48° + 모름(45° 가정)
> 아이언 로프트 세대(스트롱/전통) 판별 + 웨지 갭 계산에 함께 씁니다.

**I14. 예산은?** *(기존 유지)*
순정이면 충분 / 애프터마켓까지 / 상관없음

### ❓ 아이언 — 검토 필요 항목

1. **현재 아이언 모델 직접 입력**을 받을까요?
   - 있으면: "지금 T200 쓰시는데 새로 살 이유가 없습니다" 같은 진짜 KEEP 판정이 가능
   - 없으면: I7(아쉬운 점)만으로 간접 판단
   - 부담: 자유 입력은 오타·모델명 혼란. **드롭다운은 모델이 너무 많아 불가능**
   - 👉 제안: **선택 입력**으로 두고, 못 알아들으면 조용히 무시

2. **I9·I10(볼자국·디봇)은 대부분 "모르겠다"** 로 답할 겁니다.
   그래도 넣는 이유: 아는 사람에겐 정확도가 크게 오르고, 모르는 사람에겐 **확인 방법을 알려주는 것 자체가 콘텐츠**입니다.
   👉 정밀 단계(건너뛰기 가능)에 두는 게 맞다고 봅니다.

3. **문항 수** — 공통 6 + 아이언 1차 8 + 정밀 6 = **최대 20문항**.
   1차 8문항까지만 해도 결과가 나오므로 실제 이탈은 낮을 것으로 봅니다. 조정 의견 주세요.

## 3. 그립 — 질문 설계 (사장님 4번)

> 그립은 **유일하게 규칙만으로 거의 확정할 수 있는 영역**입니다.
> 사이즈 표가 제조사 공표값으로 존재하고, 소재·경도는 조건이 명확합니다. 추측이 거의 없습니다.

### 그립 문항 — 3개 (모든 클럽 공통, 결과 직전)

**G1. 장갑 호수 / 손 길이**
- 남 21·22·23·24·25·26호 / 여 18·19·20·21호 / **모름**
- `모름` → 손 길이 직접 입력: **가운뎃손가락 끝 ~ 손목 주름** (cm)

**G2. 손·환경** (복수 선택) 🆕
- 손에 땀이 많아요
- 여름·비 오는 날에도 라운드해요
- 손가락·손목 관절이 아파요
- 장갑을 안 껴요
- 해당 없음

**G3. 그립 압력과 타감** 🆕
- 쥐는 힘: 꽉 쥠 / 보통 / 부드럽게
- 타감: 부드러운 고무 / 단단하고 또렷 / 상관없음

### 추천 규칙 (전문 근거)

**사이즈** — 골프프라이드 공표 사이징표

| 손 길이 (중지 끝~손목 주름) | 그립 |
|---|---|
| ~17.8cm 미만 | 언더사이즈 |
| 17.8 ~ 21cm | 스탠다드 |
| 21 ~ 23.5cm | 미드사이즈 |
| 23.5cm 초과 | 점보 |

> ⚠️ **한국 장갑 호수 ↔ 미국 S/M/L 대응은 브랜드마다 다릅니다.**
> 호수만으로 단정하지 말고 **손 길이를 우선**으로 쓰고, 호수만 있을 땐 "○○ 근처" 로 범위 표기.
> (절대 원칙 2)

**보정 규칙**
| 조건 | 조치 | 이유 |
|---|---|---|
| 훅 · 손을 과하게 씀 | 한 단계 굵게 또는 **리듀스드 테이퍼**(하부가 두꺼운 것) | 손 동작이 줄어 페이스가 덜 닫힘 |
| 슬라이스 · 릴리즈가 안 됨 | 굵게 가지 않음, 스탠다드 유지 | 굵으면 릴리즈가 더 막힘 |
| 땀 많음 · 여름·우천 | **하프코드/풀코드** | 젖어도 미끄러지지 않음 |
| 관절통 · 손 힘 약함 | **오버사이즈 + 소프트 러버** | 쥐는 힘이 덜 들고 충격 흡수 |
| 후반 체력 저하 (C5) | **무거운 그립(카운터밸런스)** | 헤드 체감 무게가 줄어 후반 스윙이 유지됨 |
| 부드러운 타감 선호 | 소프트 러버 | |
| 장갑 미착용 | 코드 제외, 택키한 러버 | 코드는 맨손에 거칩니다 |

**퍼터 그립은 별도** — 아래 P11.

## 4. 퍼터 — 질문 설계 (사장님 6번)

### 퍼터 피팅이 결정하는 것

| 결정 항목 | 근거 | 질문 |
|---|---|---|
| 헤드 밸런스 (토우행/페이스밸런스) | 스트로크 궤도 | P1 |
| 헤드 모양·관성 | 미스 유형 + 취향 | P2, P4 |
| 길이 | 키 + 손목–바닥 + 눈 위치 | C2, C3, P7, P8 |
| 라이각 | 짧은 퍼트 미스 방향 + 셋업 | P3, P8 |
| 로프트 | 손 위치(포워드 프레스) | P10 |
| 헤드 무게 | **그린 빠르기** + 거리감 | P9, P2 |
| 페이스(인서트/밀드) | 타감 선호 + 그린 빠르기 | P6, P9 |
| 정렬선 | 조준 습관 | P5 |
| 그립 | 손 사용량 · 떨림 | P11 |

### 퍼터 1차 — 6문항

**P1. 퍼팅할 때 헤드가 어떻게 움직이나요?** *(기존 + 자가진단 안내 추가)* 🆕
곧게 왔다갔다 / 살짝 안쪽으로 / 많이 둥글게 / **잘 모르겠어요**
> 🆕 자가진단 안내: *"짧은 퍼트에서 페이스가 열렸다 닫히는 느낌이 있으면 아크,
> 계속 목표를 보고 있으면 직선입니다."* + `모르겠어요` → 키·스트로크 길이로 **약아크**를 기본 가정

**P2. 퍼팅에서 더 아쉬운 쪽은?** *(기존 유지)*
거리감 / 방향 / 딱히 없음

**P3. 짧은 퍼트는 어느 쪽으로 빗나가나요?** 🆕
왼쪽(당김) / 오른쪽(밀림) / 일정하지 않음 / 잘 안 놓쳐요

**P9. 주로 라운드하는 그린은?** 🆕 — 한국 특화

> 느린 그린 = **무거운 헤드 + 단단한 페이스**, 빠른 그린 = 가벼운 헤드 + 부드러운 인서트.

**P10. 어드레스에서 손 위치는?** 🆕 — 로프트 근거

> 손이 앞이면 로프트가 죽으므로 **정적 로프트가 더 있는 퍼터**가 맞습니다.

**P11. 퍼터 그립은?** 🆕

＋ ☑ 짧은 퍼트에서 손이 굳거나 떨려요
> 체크 시 오버사이즈 + 카운터밸런스 안내. (암락·롱퍼터는 **언급만**, 추천은 보류 — 데이터 없음)
