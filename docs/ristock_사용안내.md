# Ri_Stock 사용 안내

주식 분석표를 **매일 저절로 만들어 폰으로 보는 앱**입니다.
사장님이 아무것도 누르지 않아도 하루 두 번 데이터가 새로 채워집니다.

> ⚠ 이 앱은 **스크리닝 참고자료**일 뿐 투자 권유가 아닙니다. 투자 판단과 책임은 본인에게 있습니다.

---

## 1. 폰에서 열기 (제일 먼저 이것부터)

주소는 이것 하나입니다.

```
https://brownrigoon-commits.github.io/Ri-weather/ristock/
```

한 번 열어 보고, **홈 화면에 아이콘을 만들어 두면** 앱처럼 쓸 수 있습니다.

### 무엇이 보이나요

| 화면 | 내용 |
|---|---|
| **오늘 브리핑** | 오늘 시장 분위기 한 줄 · 섹터 순위 · **어제와 달라진 것**(새로 들어온 종목 / 빠진 종목) |
| **전략** | 전략 8가지 → 고르면 한국·미국 섹터별로 5종목씩 |
| **나만의 전략** | 조건을 켜고 끄면 그 자리에서 다시 계산됩니다 (폰에 기억됩니다) |
| **종목** | 시총 300 목록 · 검색 · 점수 상세 · ☆ 관심종목 |
| **내보내기** | 지금 보이는 결과를 엑셀 파일로 저장 |

**아이폰**
1. 사파리(Safari)로 위 주소를 엽니다. ※ 크롬 말고 사파리여야 합니다.
2. 아래 가운데 **공유 버튼**(네모에 화살표 ↑) 을 누릅니다.
3. 목록을 내려서 **"홈 화면에 추가"** 를 누릅니다.
4. 오른쪽 위 **추가** 를 누르면 끝. 홈 화면에 아이콘이 생깁니다.

**안드로이드(갤럭시 등)**
1. 크롬으로 위 주소를 엽니다.
2. 오른쪽 위 **점 세 개(⋮)** 를 누릅니다.
3. **"홈 화면에 추가"** 를 누르고 **추가**.

### 홈 화면에 추가하면 뭐가 달라지나요

| | 사파리로 열 때 | 홈 화면 아이콘으로 열 때 |
|---|---|---|
| 주소창 | 위아래로 보임 | **없음** — 화면을 그만큼 더 씁니다 |
| 앱 목록 | 없음 | 아이폰 앱 전환기에 따로 뜹니다 |
| 시작 화면 | 흰 화면이 잠깐 | **Ri Stock 로고 화면**이 뜹니다 |
| 지하철·비행기 | 안 열림 | 마지막으로 받은 데이터가 그대로 보입니다 |

관심종목(☆)과 나만의 전략은 **사파리와 홈 화면 앱이 같이 씁니다.** 한쪽에서 별을 누르면 다른 쪽에도 있습니다.

> 📲 두 번째로 앱을 여시면 브리핑 맨 위에 **"홈 화면에 추가하면 앱처럼 열립니다"** 안내가 뜹니다.
> 이미 추가하셨거나 필요 없으시면 오른쪽 위 **✕** 를 누르세요. 다시 뜨지 않습니다.
>
> ※ 이 안내는 **아이폰에서만** 뜹니다. 아이폰 사파리에는 "설치" 버튼이 따로 없어서
> 앱이 직접 알려 드리는 것입니다(안드로이드 크롬은 브라우저가 알아서 물어봅니다).

## 2. 처음 한 번만 하는 설정 (집 PC에서, 5분)

> 이 설정은 **집 PC가 매일 알아서 데이터를 만들게** 하는 것입니다.
> 한 번만 해 두면 다시 할 일이 없습니다.

### 2-1. 준비물 설치

시작 메뉴에서 **PowerShell** 을 열고, 아래를 **한 줄씩** 붙여넣고 엔터를 칩니다.
(`C:\Ri-weather` 부분은 저장소를 내려받은 실제 폴더 이름으로 바꿔 주세요)

```
cd C:\Ri-weather
C:\Python314\python.exe -m pip install -r ristock\engine\requirements.txt
```

몇 분 걸립니다. 마지막에 `Successfully installed ...` 이 나오면 성공입니다.

### 2-2. 자동 실행 예약 걸기

이어서 아래를 붙여넣습니다.

```
powershell -ExecutionPolicy Bypass -File tools\ristock_스케줄등록.ps1 -등록
```

`등록 완료: RiStock_오후갱신 ...` 처럼 두 줄이 나오면 끝났습니다.
이제 **매일 16:40 과 07:10** 에 집 PC가 알아서 데이터를 만듭니다.

### 2-3. 제대로 걸렸는지 확인

```
powershell -ExecutionPolicy Bypass -File tools\ristock_스케줄등록.ps1 -상태
```

`다음 실행:` 에 날짜와 시각이 보이면 정상입니다.

> **알아두실 점** — 예약은 PC가 **켜져 있고 로그인된 상태**에서 돕니다.
> 그 시각에 PC가 꺼져 있었으면, 다음에 켜서 로그인했을 때 곧바로 한 번 돕니다.
> 그래서 PC를 며칠 안 켜도 데이터가 완전히 멈추지는 않습니다(아래 3번의 서버 실행이 있으니까요).

---

## 3. 자동 갱신은 언제 도나요

| 시각(한국시간) | 누가 | 무엇을 담나 |
|---|---|---|
| **16:30** 월~금 | 깃허브 서버 | 그날 한국 장 마감 결과 |
| **16:40** 매일 | 집 PC | 위와 같음 (서버가 실패했을 때의 보험) |
| **07:00** 화~토 | 깃허브 서버 | 밤사이 미국 장 마감 결과 |
| **07:10** 매일 | 집 PC | 위와 같음 (보험) |

**왜 두 군데서 도나요?**
깃허브 서버는 외국 IP라서 네이버 금융이 가끔 막습니다. 그러면 한국 데이터가 안 채워집니다.
반대로 집 PC는 꺼져 있을 수 있습니다.
**둘 중 하나만 성공해도 데이터는 채워지도록** 일부러 두 겹으로 만들었습니다.

> 📌 **지금은 서버 자동 실행이 아직 안 돕니다.**
> 깃허브의 예약 실행은 **`main` 가지에 합쳐진 뒤부터** 동작하는 규칙이 있습니다.
> 합치기 전까지는 위 표의 **집 PC 실행**과 **손으로 실행**(4번)만 동작합니다.

## 4. 지금 당장 새로 받고 싶을 때

### 방법 A — 집 PC에서 (가장 확실함)

파일 탐색기에서 저장소 폴더 → `tools` 폴더 → **`ristock_실행.bat` 을 더블클릭**합니다.

- 까만 창이 뜨고 **8~15분** 걸립니다. **창을 닫지 마세요.**
- 다 되면 "완료되었습니다" 가 나오고 10초 뒤 저절로 닫힙니다.
- 실패하면 창이 그대로 남아 이유를 보여 줍니다.
- **"일부만 갱신됐습니다"** 가 나오면 한쪽 시장만 채워진 것입니다.
  앱은 정상이고, 채워지지 않은 쪽은 어제 데이터가 그대로 보입니다. 잠시 뒤 한 번 더 돌려 보세요.
- 1~2분 뒤 폰에서 새로고침하면 새 데이터가 보입니다.

### 방법 B — 폰이나 PC에서 버튼으로 (PC를 안 켜도 됨)

1. 브라우저에서 저장소의 **Actions** 탭을 엽니다.
   `https://github.com/brownrigoon-commits/Ri-weather/actions`
2. 왼쪽 목록에서 **"Ri_Stock 일일 자동 갱신"** 을 누릅니다.
3. 오른쪽의 **Run workflow** 버튼을 누릅니다.
4. 그대로 두고 초록색 **Run workflow** 를 한 번 더 누르면 시작됩니다.
   - `market` : `all`(미국+한국) / `us`(미국만) / `kr`(한국만)
   - `top` : 시가총액 상위 몇 종목까지 볼지 (기본 300)
   - `no_news` : 급할 때 뉴스를 빼고 빨리 돌리기.
     종목별 뉴스·수급 점수와 시장 분위기 요약이 **둘 다** 비게 됩니다. 평소에는 켜지 마세요.
5. 10~20분 뒤 폰에서 새로고침.

## 5. 잘 돌았는지 확인하는 법

**폰에서** — 앱 첫 화면 위쪽에 **데이터 날짜**가 있습니다. 오늘 또는 어제면 정상입니다.
데이터가 3일 이상 지나면 앱이 눈에 띄게 알려 줍니다.

**집 PC에서**

```
powershell -ExecutionPolicy Bypass -File tools\ristock_스케줄등록.ps1 -상태
```

- `지난 실행 ... 결과코드 0` → 정상
- 맨 아래에 마지막 실행 기록 몇 줄이 함께 나옵니다.

**깃허브에서** — Actions 탭에서 초록색 ✔ 이면 성공, 빨간 ✘ 이면 실패입니다.
줄을 눌러 들어가면 **미국 수집 / 한국 수집** 이 각각 성공했는지 표로 보입니다.

### 📬 문제가 생기면 알아서 알려 줍니다 (Actions 탭을 안 봐도 됩니다)

한쪽 시장(주로 한국)만 채워지지 않으면 예전에는 초록불로 끝나 알 방법이 없었습니다.
이제는 **저장소 Issues 탭에 알림이 하나 열리고 메일이 옵니다.**

- 알림 제목: `🔴 Ri_Stock 자동 갱신 — 한국 데이터가 채워지지 않았습니다`
- 그 안에 **연속 몇 번 실패했는지**와 무엇을 하면 되는지가 적혀 있습니다.
- **같은 문제로 매일 메일이 오지는 않습니다.** 처음 한 번, 그 뒤로는 5회마다 한 번만 다시 알립니다.
- 데이터가 다시 채워지면 그 알림은 **저절로 닫힙니다.** 손대지 않으셔도 됩니다.
- 미국·한국이 **둘 다** 실패한 날은 Actions 실행 자체가 빨간 ✘ 로 끝나 메일이 옵니다.
- 저장소의 **Issues 기능이 꺼져 있으면** 알림을 열 수 없습니다. 그때는 알림 대신
  Actions 실행이 빨간 ✘ 로 끝나 메일이 옵니다 — 어느 쪽이든 **모르고 지나가는 일은 없습니다.**

> 알림이 떠도 **앱은 멀쩡합니다.** 채워지지 않은 쪽만 이전 날짜 데이터로 보일 뿐이고,
> 지워지는 것은 없습니다.

## 6. 문제가 생겼을 때

### 데이터가 며칠째 그대로예요

1. 집 PC를 켜고 `tools\ristock_실행.bat` 을 더블클릭해 봅니다 (4번 방법 A).
2. 그래도 안 되면 창에 나온 문구를 그대로 캡처해 두세요.
3. 자세한 기록은 이 파일에 있습니다: `ristock\data\last_run.log`

### 한국 데이터만 비어 있어요

거의 항상 **네이버 금융이 깃허브 서버 IP를 막아서** 생기는 일입니다.
**집 PC에서 한 번 돌리면 바로 채워집니다.** (4번 방법 A)

이때도 **미국 데이터와 어제 한국 데이터는 지워지지 않습니다.**
한쪽이 실패해도 멀쩡한 데이터를 덮어쓰지 않도록 만들어 두었습니다.

이런 일이 생기면 Issues 탭에 알림이 자동으로 열립니다(5번 참고).
집 PC에서 한 번 돌려 데이터가 채워지면 그 알림은 저절로 닫힙니다.

### 앱이 옛날 화면으로 보여요

폰 브라우저에서 **아래로 당겨 새로고침**을 두 번 해 보세요.
그래도 옛날 화면이면 홈 화면 아이콘을 지우고 1번을 다시 하면 됩니다.

### 까만 창에 "git 이 설치되어 있지 않습니다" 가 떠요

`https://git-scm.com` 에서 Git 을 설치한 뒤 다시 더블클릭하면 됩니다.

### 까만 창에 "파이썬을 찾지 못했습니다" 가 떠요

`C:\Python314\python.exe` 가 있는지 확인해 주세요. 없으면 파이썬을 다시 설치해야 합니다.

### "데이터를 맞추지 못했습니다. 사람이 확인해야 합니다"

집 PC와 회사 PC가 같은 파일을 동시에 고쳤을 때 나옵니다. 아래를 실행해 보세요.

```
python tools\sync.py --status
python tools\sync.py "정리"
```

## 7. 자동 갱신을 잠시 멈추고 싶을 때

```
powershell -ExecutionPolicy Bypass -File tools\ristock_스케줄등록.ps1 -해제
```

다시 켜려면 `-등록` 으로 실행하면 됩니다.
멈춰 둔 동안에도 `ristock_실행.bat` 더블클릭으로는 언제든 갱신할 수 있습니다.

## 8. 알아두면 좋은 것

- **엑셀 분석표**는 갱신할 때마다 `내 문서\Ri_Stock` 폴더에 저장됩니다.
  (깃허브에서 돌린 경우에는 Actions 실행 화면 아래쪽 **첨부파일**에서 14일간 내려받을 수 있습니다)
- 앱이 읽는 데이터 파일은 `ristock\data\` 폴더에 있고, 자동으로만 만들어집니다.
  **손으로 고치지 마세요.** 다음 갱신 때 통째로 덮어쓰입니다.
- 날짜별 원본은 `ristock\data\archive\` 에 쌓이는데 **오래된 것은 자동으로 정리됩니다.**
  최근 60번치를 남기고, 그보다 오래된 것 중에서도 **각 달의 마지막 거래일은 남깁니다.**
  (그래서 몇 달 전 상황도 되짚어 볼 수 있고 폴더가 무한정 커지지도 않습니다)
- 이 archive 폴더는 **내 PC 에만 있습니다.** 깃허브에는 올리지 않습니다
  (한 번에 0.6MB 씩 쌓여 저장소가 매년 40MB 가까이 무거워지고, 집·회사 두 PC 의
  받기·올리기가 그만큼 느려지기 때문입니다). 회사 PC 에는 회사 PC 가 돌린 날짜만 쌓입니다.
- 앱은 언제나 **최신 파일만** 읽습니다. archive 폴더는 기록용입니다.
  '어제 대비 신규 편입/이탈'은 archive 가 아니라 `ristock\data\picks_baseline.json`
  (전략이 뽑은 종목 목록만 담은 20KB 짜리 작은 파일)로 계산하므로,
  archive 폴더를 통째로 지워도 앱 화면은 아무 영향이 없습니다.
