# 02. 데이터 소스 — 엑셀 (P1의 주 소스, 완전 동작해야 함)

실무자가 이지어드민에서 내려받은 엑셀을 지정 폴더에 넣으면 서버가 읽는다.
파일명은 자유. 서버가 최신 파일을 자동 인식한다.

## 폴더 규약

기본 위치 `<프로젝트>/data` (`.env`의 `EZMCP_DATA_DIR`로 변경 가능). 시작 시 없으면 자동 생성.

| 폴더 | 내용 | 사용하는 도구 |
|---|---|---|
| `data/orders/` | 주문 엑셀 (송장·배송상태 컬럼 포함된 주문 목록) | order_lookup, unshipped_list, shipping_lookup |
| `data/inventory/` | 재고 엑셀 | inventory_lookup |
| `data/returns/` | 반품·교환(클레임) 엑셀 — 선택. 없으면 주문 데이터의 반품/교환 상태로 대체하고 warnings에 명시 | shipping_lookup(반품), order_lookup |

- **하위 폴더 재귀 스캔.** 브랜드별 이지어드민 계정이 분리된 경우 `data/orders/루미네/`,
  `data/orders/베르디/`처럼 나눠 넣어도 전부 읽는다 (하위 폴더명은 매칭에 사용하지 않음, 단순 정리용)
- 지원 확장자: `.xlsx`, `.csv`. 임시파일(`~$*`)은 무시. `.xls`(구형)는 읽지 않고
  "xlsx로 다시 내려받거나 다른 이름으로 저장하세요" 한국어 오류를 warnings로 반환

## 파일 병합·중복 제거

1. 폴더 내 모든 파일을 mtime 오름차순으로 읽어 레코드를 합친다
2. 중복 키가 같으면 **나중(더 최신) 파일의 행이 이긴다**
   - 주문: `주문번호 | 상품코드(없으면 상품명) | 옵션`
   - 재고: `상품코드(없으면 상품명) | 옵션`
   - 반품: `주문번호 | 상품명 | 접수일`
3. meta.files에는 읽은 파일 전부(이름+수정시각), 데이터기준은 가장 최신 mtime
4. 최신 파일이 24시간보다 오래되면 warnings에 신선도 경고 추가

## CSV 인코딩

`utf-8-sig` → 실패 시 `cp949` 순서로 시도. 둘 다 실패하면 해당 파일 건너뛰고 warnings에 기록.

## 헤더 행 자동 탐지

이지어드민 엑셀은 위에 제목·조회조건 행이 붙을 수 있다.
상위 10행을 훑어 **후보 헤더명과 3개 이상 일치하는 첫 행**을 헤더로 삼고 그 아래를 데이터로 읽는다.
못 찾으면 그 파일은 건너뛰고 warnings에 파일명을 기록한다.

## 헤더 정규화와 표준 필드 매핑

헤더 문자열을 정규화(소문자화, 공백·`(` `)` `[` `]` 제거)한 뒤 아래 후보와 비교한다.
매칭은 2패스: ① 정확 일치 우선 ② 남은 컬럼에 대해 부분 포함 일치.
한 필드에 여러 컬럼이 걸리면 먼저 나온 컬럼을 쓴다. 후보 목록은 `config.json`의
`columns` 섹션으로 계정별 커스텀 헤더를 추가할 수 있다(기본값 대체가 아니라 추가).

## 상태 정규화 (버킷)

`status`(없으면 `ship_status`) 문자열을 정규화 후 **아래 순서대로** 부분 포함 검사한다.
순서가 중요하다(예: "반품완료"가 배송완료로 빠지면 안 되므로 반품을 먼저 검사).

| 검사 순서 | 버킷 | 포함 키워드 (기본값, config `status_keywords`로 추가 가능) |
|---|---|---|
| 1 | 취소 | 취소 |
| 2 | 반품 | 반품 |
| 3 | 교환 | 교환 |
| 4 | 배송완료 | 배송완료, 구매확정, 수취확인, 배달완료 |
| 5 | 배송준비 | 배송준비, 상품준비, 출고대기, 출고지시, 송장출력, 미출고, 발주확인, 준비중 |
| 6 | 배송중 | 배송중, 출고완료, 발송완료, 발송처리, 집화 |
| 7 | 신규주문 | 신규, 주문확인, 결제완료, 입금확인, 접수 |
| 8 | 보류 | 보류, 품절 |
| — | 기타 | (어디에도 안 걸림 — 원문 그대로 보존, data_status가 "기타" 상태값 목록을 보여줌) |

`ship_status`가 별도로 있으면 우선 규칙: status 버킷이 {신규주문, 배송준비, 기타}인데
ship_status가 배송중/배송완료로 판정되면 ship_status 버킷을 채택한다.

⚠️ 실제 이지어드민 상태값은 계정 설정에 따라 다르다. **실데이터 검증 시 "기타"로 빠지는
상태값을 확인해 config에 추가하는 것까지가 구현 완료 조건이다** (08 문서 체크리스트).

## 값 파싱

- **날짜**: datetime/date 셀은 그대로. 문자열은 다음 형식 순서로 시도 —
  `%Y-%m-%d %H:%M:%S`, `%Y-%m-%d %H:%M`, `%Y-%m-%d`, `%Y/%m/%d %H:%M:%S`, `%Y/%m/%d`,
  `%Y.%m.%d`, `%Y%m%d`. 숫자 30000~80000은 엑셀 시리얼(1899-12-30 기준)로 해석.
  실패하면 None(기간 필터에서 제외되며, 필터 없는 조회에는 포함)
- **금액·수량**: 콤마·`원`·`₩`·공백 제거 후 int. 실패 시 0
- 모든 값은 str.strip() 후 사용. 빈 문자열은 None 취급
